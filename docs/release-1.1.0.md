# 自动对账工具 1.1.0

- 报价和采购／送货记录在导入前可直接修改，支持双击单元格、整行修改、错误筛选和搜索。
- 修改完成可确认导入；未完成可阅读提醒后强制导入。错误字段保留原文，不按0计算，正式账单仍要求完成核对。
- 已导入记录可继续修改，受影响的匹配重新核对；保存进度和导出来源页保留原值、修改历史。
- 修复Windows高DPI下文字缩放和行高，调整布局保留底部操作区。

Windows 10/11 x64，下载Setup安装包后双击安装，无需Python或Microsoft Excel。使用同一安装目录可以升级旧版。校验文件为同名.sha256。

验证：25项回归测试通过，真实GUI编辑/强制导入流程通过，安装、已安装GUI、样例导出和卸载测试通过。原始业务样例不包含在发布附件中。
